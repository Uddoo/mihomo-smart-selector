Mihomo Smart Selector 的首个 GitHub 预发布版本，提供 Windows 和 macOS 便携包。
程序内嵌网页与 SQLite，解压后运行，无需安装 Go、Node.js 或 Python。

| 下载文件后缀 | 适用设备 | 验证范围 |
| --- | --- | --- |
| `windows-amd64.zip` | Intel / AMD x64 Windows | 原生 Windows 启动、配置与服务重启测试 |
| `windows-arm64.zip` | Windows on ARM | 交叉构建；尚未在 ARM64 Windows 上运行验证 |
| `darwin-arm64.tar.gz` | Apple Silicon Mac | 原生 Apple Silicon 启动、配置与服务重启测试 |
| `darwin-amd64.tar.gz` | Intel Mac | 原生 Intel macOS 启动、配置与服务重启测试 |
| `SHA256SUMS.txt` | 所有平台 | 上述四个归档的 SHA-256 校验值 |

本版重点：

- 偏好设置新增 **重启服务**。保存连接后直接应用，Controller 离线时仍可恢复并进入设置；
  扫描过程中禁止重启，后台监控在重启后恢复。
- 嵌套策略组显示可扫描的下级 Selector、路径和候选数量，适用于 Clash Party、OpenClash
  等 Mihomo 客户端。进入下级组时保留测试服务；确认切换作用于所选下级组，也可能影响共用该组的服务。
- Windows 与 macOS 首次启动均在程序同目录创建配置，已有配置完整保留。
- 包含节点扫描、评分、显式切换、历史、监控和图形化连接配置；监控自动切换默认关闭。

Windows：解压 ZIP 后运行 `mihomo-smart-selector.exe`。
macOS：解压 `.tar.gz` 后双击 `start.command`，或在终端运行 `./mihomo-smart-selector`。
打开 http://127.0.0.1:8788，在偏好设置填写 Controller 的 HTTP(S) 地址及密钥，测试、保存并重启服务。

系统基线为 Windows 10 / Server 2016+、macOS 13 Ventura+。Windows 构建暂无 Authenticode 签名；
macOS 构建暂无 Apple Developer ID 签名及公证，Gatekeeper 可能要求逐应用允许打开。
程序需要用户可写目录。升级前退出程序，备份并保留 `config.yaml`、完整 `data/` 及外部密钥文件。

First GitHub prerelease with portable Windows and macOS builds. Extract the archive for your
CPU architecture and run the executable (or `start.command` on macOS). No language runtimes are needed.
First launch creates configuration beside the executable. Open http://127.0.0.1:8788 to configure
the HTTP(S) Mihomo Controller in Settings.

Settings now supports a confirmed service restart, including recovery with an offline Controller.
Nested groups offer explicit navigation to child Selectors while preserving the probe profile.
Selecting a child can affect other services sharing that group. Monitoring automatic failover is off by default.

Windows AMD64 and both macOS architectures receive native runtime checks; Windows ARM64 is
cross-built only. Minimum systems: Windows 10 / Server 2016 and macOS 13 Ventura.
Windows binaries have no Authenticode signature; macOS packages have no Developer ID signature or Apple notarization.
Verify archives using `SHA256SUMS.txt`. Before upgrading, stop the program and retain configuration,
the entire data directory and secret files. See the included platform README for installation and recovery.
