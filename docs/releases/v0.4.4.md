**前端依赖与构建维护版本。** `v0.4.4` 更新前端和自动化依赖，重新生成内嵌页面，并让页面加载恢复测试兼容新版浏览器的重试行为。

## 本次更新

- Lucide Vue 从 1.49.0 升级至 1.53.0，Vite 从 8.3.2 升级至 8.3.4，并同步锁定的 Rolldown 1.2.13 和 PostCSS 8.5.29。
- Playwright 从 1.63.0 升级至 1.64.0，锁定的 vue-tsc 从 3.3.11 升级至 3.3.12。
- 重新生成 Go 内嵌前端、gzip 资源和入口引用，使下载包中的页面与依赖锁文件一致。
- 页面加载恢复回归测试现在会明确阻断重试请求，覆盖浏览器缓存失败或重新请求动态模块两种行为，保留错误提示与重新加载恢复的断言。
- GitHub Actions 的 upload-artifact 升级至 7.0.2、download-artifact 升级至 8.0.2、CodeQL Action 升级至 4.38.3，保持完整 SHA 固定。

## 升级与兼容性

1. 配置格式、API 和数据库结构与 v0.4.3 一致，已有服务绑定、监控任务和历史数据可继续使用。
2. 升级前停止服务，备份程序、配置和完整数据目录，再替换程序并启动；更早版本请同时遵循对应的迁移说明。
3. 升级后刷新浏览器页面以加载新的前端资源。从源码构建时继续使用 Go 1.27.2 或更高版本。

## 下载与校验

提供 Windows AMD64/ARM64 ZIP、macOS Apple Silicon/Intel tar.gz 和 `SHA256SUMS.txt`。Windows AMD64 与两种 macOS 架构有 CI 原生包运行验证；Windows ARM64 仅交叉构建。包未签名，macOS 未公证。Linux / OpenWrt / iStoreOS 按架构从源码构建，沿用现有安装方式。

发布流水线执行 Go/race、进程 smoke、前端和浏览器回归、安全扫描、桌面包运行验证及附件校验和检查。

## English

`v0.4.4` is a frontend dependency and build maintenance release. It updates Lucide Vue to 1.53.0, Vite to 8.3.4 with Rolldown 1.2.13 and PostCSS 8.5.29, Playwright to 1.64.0, and the locked vue-tsc to 3.3.12. The embedded frontend and gzip assets are regenerated to match the lockfile. The page-load recovery regression explicitly fails retried module downloads, preserving error and reload checks across browser retry behavior. GitHub artifact actions and CodeQL Action are updated with full commit SHA pins.

Configuration, API and database formats remain compatible with v0.4.3. Existing service bindings, monitoring tasks and historical records can be retained. Stop the service and back up the program, configuration and complete data directory before replacing the binary, then refresh the browser. Follow earlier migration notes when upgrading from older versions. Source builds continue to require Go 1.27.2 or later.

Verify downloads with `SHA256SUMS.txt`. Windows ARM64 is cross-built only; Windows AMD64 and both macOS architectures receive native CI package checks. Packages are unsigned and macOS packages are not notarized. Linux and router installations continue to use source builds.
