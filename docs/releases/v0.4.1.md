**为 AI 服务选择专属探测模板。** `v0.4.1` 新增 Claude、Gemini、Google AI Studio、DeepSeek 和 Mistral AI 内置模板，可用于节点扫描、绑定和持续监控。

## 本次更新

- Claude、DeepSeek、Mistral AI：检查各自站点静态资源的可达性与时延。
- Gemini：检查 Gemini Web 入口；Google AI Studio：检查 Gemini API 公开 Discovery 元数据入口。
- 支持对应服务组名推荐，忽略大小写、空格、emoji 和标点；任意名称的 Selector 也可手动选择模板并保存绑定。
- 补齐中英文说明、使用文档和内嵌前端资源，扩展模板解析、绑定持久化与扫描回归覆盖。

无需 API 密钥，不发送模型生成请求。这些入口可达不代表账号登录、模型对话、Claude Code、API 调用、地区资格或付费功能可用。Gemini 的登录或地区提示页也可能返回 200。新增模板没有严格验证规则；ChatGPT 原有可选 API 401 验证保留。

## 升级与兼容性

1. 使用默认内置目录时，更新程序并刷新网页即可选择新模板。`AI服务` 继续推荐 ChatGPT，`谷歌服务` 继续推荐通用 Google；已有绑定、监控任务和切换规则保留。
2. 显式设置 `scanner.probe_profiles` 仍会完整替换内置目录，需要自行加入所需模板。
3. 检查 `custom_probe_profiles` 是否使用 `claude`、`gemini`、`aistudio`、`deepseek` 或 `mistral`。同名 ID 会触发配置校验错误，应先改名或迁移为 `probe_profile_overrides`；改名后更新相关绑定和任务。
4. 从 v0.4.0 升级不新增数据库结构迁移。升级前停止服务，备份程序、配置及完整数据目录；运行中的 SQLite 不能只备份单个数据库文件。从更早版本升级时，同时遵循对应版本迁移说明。

## 下载与校验

提供 Windows AMD64/ARM64 ZIP、macOS Apple Silicon/Intel tar.gz，以及 `SHA256SUMS.txt`。Windows AMD64 与两种 macOS 架构由 CI 原生验证；Windows ARM64 仅交叉构建。包未签名，macOS 包未公证。Linux / OpenWrt / iStoreOS 继续按架构从源码构建，不新增 Linux 下载附件。

发布流水线执行 Go/race、进程 smoke、前端和浏览器回归、安全检查及桌面包校验。公网探测地址会随服务商策略变化，可使用配置覆盖；本版本不保证任意节点的业务访问能力。

## English

`v0.4.1` adds built-in profiles for Claude, Gemini Web, Google AI Studio, DeepSeek and Mistral AI, available to scans, saved bindings and monitoring. Selector aliases and Chinese/English descriptions are included.

Probes require no AI credentials and make no generation requests. Static resources, Web entry points and Discovery metadata only establish endpoint reachability, not account access, model generation, Claude Code, regional eligibility or subscriptions. The five new profiles have no strict rules; existing ChatGPT checks remain available.

Default catalogs automatically gain these profiles. Explicit `scanner.probe_profiles` still replaces the full catalog. Custom IDs matching `claude`, `gemini`, `aistudio`, `deepseek` or `mistral` must be renamed or migrated to `probe_profile_overrides` before upgrading. Update bindings and tasks if renaming IDs. No database migration is added over v0.4.0; stop the service and back up the program, configuration and complete data directory before replacement.

Download Windows AMD64/ARM64 or macOS Apple Silicon/Intel archives and verify `SHA256SUMS.txt`. Windows ARM64 is cross-built only; other desktop targets receive native CI package checks. Packages are unsigned and macOS packages are not notarized. Linux/router builds use the documented source-build path.
