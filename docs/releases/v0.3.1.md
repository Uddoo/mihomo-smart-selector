**依赖与构建维护版本。** `v0.3.1` 更新前端依赖和 CI 工具链，并同步 Go 程序内嵌的前端资源，保留 `v0.3.0` 的功能、API、数据库结构和切换规则。

## 本次更新

- **前端依赖**：Lucide Vue 1.47.0 → 1.48.0、Vite 8.3.0 → 8.3.1、Prettier 3.9.8 → 3.9.9，并同步锁定的 Rolldown 依赖。
- **内嵌资源同步**：重新生成受影响的 JavaScript、对应 gzip 文件和 HTML 入口引用，确保发布程序携带的页面与依赖锁文件一致。
- **CI 工具链**：CodeQL init/analyze 同步更新到 4.38.2，pnpm/setup 更新到 3.0.0。继续固定 Node.js 22.12.0 和 pnpm 11.19.0，使用冻结锁文件安装。

对应 PR：[前端依赖与产物 #21](https://github.com/Uddoo/mihomo-smart-selector/pull/21)、[CodeQL #22](https://github.com/Uddoo/mihomo-smart-selector/pull/22)、[pnpm/setup #23](https://github.com/Uddoo/mihomo-smart-selector/pull/23)。

## 验证范围

合并前的最终提交通过 98 项前端单元测试、99 项浏览器回归、Go 竞态测试、进程级冒烟测试、依赖与密钥检查，以及 CodeQL 分析。91 个内嵌静态文件与生产构建逐一匹配。发布流水线按标签重新执行完整验证、跨平台构建、安装包运行检查和下载校验。

## 升级与兼容性

1. **从 v0.2.0 或 v0.3.0 升级不新增数据库结构迁移。** 停止服务，备份旧程序、配置、完整数据目录和外部密钥文件，再替换程序启动。SQLite 可能包含 WAL，备份时保留完整数据目录。
2. 升级后重新加载网页；使用 Token 认证时重新输入 Token，并确认监控任务、候选和自动切换偏好。
3. 从 v0.1.0 或更早版本升级，仍需遵循 [v0.2.0 的多任务迁移与回退说明](https://github.com/Uddoo/mihomo-smart-selector/blob/v0.3.1/docs/releases/v0.2.0.md#升级与兼容性)。
4. 本次不改变 API 响应契约、监控任务身份、保留配额、探测并发或故障自动切换规则。

## English

`v0.3.1` is a dependency and build maintenance release. It updates Lucide Vue to
1.48.0, Vite to 8.3.1 and Prettier to 3.9.9, together with locked Rolldown
dependencies. The Go-embedded JavaScript, gzip assets and HTML entry references
are regenerated to match the updated lockfile.

CodeQL init/analyze are updated together to 4.38.2, and pnpm/setup to 3.0.0.
Node.js 22.12.0, pnpm 11.19.0 and frozen-lockfile installation remain pinned.
The final PR head passed 98 frontend unit tests, 99 browser regressions, Go race
tests, process smoke tests, security scans and CodeQL. All 91 embedded files
matched the production build. The release workflow repeats verification and
platform packaging checks from the release tag.

**Upgrading from v0.2.0 or v0.3.0 adds no schema migration.** Stop the service and
back up the executable, configuration, complete data directory and external
secrets before replacing the executable. Reload the UI and re-enter the API
token afterward. Upgrades from v0.1.0 still perform the task migration described
in the v0.2.0 notes; downgrading across that schema boundary requires the matching
database backup. API contracts, task identity, retention limits, probe concurrency
and automatic failover rules are unchanged.

Four desktop archives and `SHA256SUMS.txt` are provided. Windows AMD64 and both
macOS architectures receive native CI checks; Windows ARM64 is cross-built only.
Packages remain unsigned and macOS packages are not notarized. Linux/router
binaries continue to use the documented source-build path.
