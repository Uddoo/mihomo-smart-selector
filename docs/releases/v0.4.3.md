**依赖与安全维护版本。** `v0.4.3` 更新数据库和前端构建依赖，修复安全基线，并同步交付内嵌前端资源。

## 本次更新

- SQLite 从 1.59.0 升级至 1.60.1，配套 libc 1.77.1 和 x/sys 0.48.0。
- Lucide Vue 升级至 1.49.0，Vite 升级至 8.3.2，同步更新锁定的 Rolldown 依赖。
- 最低 Go 版本提升至 1.27.2，发布构建采用该工具链修复标准库安全问题。
- 将 Vue 编译器、vue-tsc 和 PostCSS 等全部传递依赖路径中的 source-map-js 统一到 1.2.2。
- 重新生成内嵌前端、gzip 资源和入口引用，确保下载包中的页面与依赖锁文件一致。

## 升级与兼容性

1. 配置格式和数据库结构与 v0.4.2 一致，已有服务绑定、监控任务和历史数据可继续使用。
2. 升级前停止服务，备份程序、配置和完整数据目录，再替换程序并启动；更早版本请同时遵循对应的迁移说明。
3. 升级后刷新浏览器页面以加载新的前端资源。从源码构建时使用 Go 1.27.2 或更高版本。

## 下载与校验

提供 Windows AMD64/ARM64 ZIP、macOS Apple Silicon/Intel tar.gz 和 `SHA256SUMS.txt`。Windows AMD64 与两种 macOS 架构有 CI 原生包运行验证；Windows ARM64 仅交叉构建。包未签名，macOS 未公证。Linux / OpenWrt / iStoreOS 按架构从源码构建，沿用现有安装方式。

发布流水线执行 Go/race、进程 smoke、前端和浏览器回归、安全扫描、桌面包运行验证及附件校验和检查。

## English

`v0.4.3` is a dependency and security maintenance release. It updates SQLite to 1.60.1 with libc 1.77.1 and x/sys 0.48.0, Lucide Vue to 1.49.0, and Vite to 8.3.2 with the corresponding locked Rolldown updates. Builds require Go 1.27.2 or later. Every source-map-js dependency path now resolves to 1.2.2, and the embedded frontend and gzip assets are regenerated to match the lockfile.

Configuration and database formats remain compatible with v0.4.2. Existing service bindings, monitoring tasks and historical records can be retained. Stop the service and back up the program, configuration and complete data directory before replacing the binary, then refresh the browser. Follow earlier migration notes when upgrading from older versions.

Verify downloads with `SHA256SUMS.txt`. Windows ARM64 is cross-built only; Windows AMD64 and both macOS architectures receive native CI package checks. Packages are unsigned and macOS packages are not notarized. Linux and router installations continue to use source builds.
