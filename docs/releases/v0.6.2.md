**升级后仍可查看历史扫描。若服务要求严格验证，且验证规则已变或旧记录缺少规则指纹，请先复测再切换。**

- 对有出口地区要求的服务，独立出口 Controller 上的同名节点须与业务节点的 Provider 和协议一致。旧结果只有地区、缺少验证来源时，也需要复测。手动复测不会切换业务组。
- 扫描预检复用短期节点目录，正式扫描重新读取成员。取消一次预检不会中断其他请求。首次打开工作台会等待表单恢复，浏览器无法写入会话存储时，当前标签页仍会跟踪已受理的扫描。临时筛选没有匹配节点时，仍可保存有效的组和服务绑定。
- 监控候选建议取自当前 Controller、组和服务最近完成的扫描，并核对当前 Provider。暂时无法读取历史扫描时，页面保留其 ID，恢复后可重试。
- 修复旧监控数据跨批次清理停滞的问题。故障切换在没有近期健康后备时跳过 24 小时排名查询，采样与切换前复测统一识别 Controller 认证和连接错误。
- 桌面下载包含 Windows 和 macOS 的 amd64、arm64 包，可使用 `SHA256SUMS.txt` 校验。OpenWrt 从源码交叉构建支持 `amd64`、`arm64`、`arm`、`386`。当前 SQLite 依赖缺少 `mips` 和 `mipsle` 支持。本版尚未在 OpenWrt 真机上验证。

## English

- Historical scans remain readable. Retest before a strict-gated switch if the verification rules changed or the stored result lacks a rule fingerprint. Region-gated selection also requires an identified egress evidence source. On an isolated egress Controller, a same-name node must match the business node's provider and protocol. A manual retest leaves the business group's selection in place.
- Scan previews share short-lived catalog reads and handle cancellation independently. Starting a scan refreshes group membership. The workbench waits for initial form restoration and tracks accepted scans in the current tab when browser storage is unavailable. A valid group and service binding can be saved even when filters match no candidates.
- Monitoring suggestions use the most recently completed scan for the current Controller, group and profile, and check the current provider. A temporary history read failure preserves the scan ID for retry.
- Monitoring history cleanup can finish across batches. Failover skips the 24-hour ranking query when it has no recently healthy backup. Sampling and failover verification classify Controller authentication and connectivity errors consistently.
- Download a Windows or macOS archive for amd64 or arm64 and verify it against `SHA256SUMS.txt`. The OpenWrt source build supports `amd64`, `arm64`, `arm` and `386`. The pinned SQLite dependencies lack `mips` and `mipsle` support. OpenWrt verification for this release covers cross-builds only.
