# Code of Conduct

## Our commitment

Mihomo Smart Selector contributors and maintainers commit to a respectful,
welcoming, and harassment-free project community regardless of experience,
identity, background, disability, appearance, nationality, religion, or other
personal characteristics.

## Expected behavior

Examples of constructive participation include:

- discussing technical evidence and trade-offs rather than attacking people;
- giving specific, actionable, and proportionate review feedback;
- acknowledging uncertainty, mistakes, and verification boundaries;
- respecting privacy and redacting network credentials and identifiers;
- keeping issues and pull requests focused on the project; and
- accepting a maintainer's decision to defer or decline a change.

Unacceptable behavior includes harassment, threats, discrimination, sexualized
content, deliberate intimidation, sustained disruption, publishing another
person's private information, or using project channels to promote unrelated
products or services.

## Scope

This Code applies in repository issues, pull requests, discussions, code review,
and other spaces where someone is representing the project. It also applies to
private maintainer communication about a project incident.

## Reporting and enforcement

Do not place private incident details in a public issue. Open a public issue
containing only a request for a private maintainer contact channel, with no
names, screenshots, logs, or incident narrative. Continue only after the
maintainer provides an appropriate private route. Security vulnerabilities must
instead follow [SECURITY.md](SECURITY.md).

Maintainers will review reports in good faith, protect reporter privacy as far
as practical, and choose a proportionate response. Depending on severity and
history, responses may include a private correction, content removal, a formal
warning, a temporary participation restriction, or a permanent ban. Retaliation
against a good-faith reporter is itself a violation.

Maintainers may remove content that violates this Code and should explain an
enforcement decision to the affected participant when doing so would not expose
another person's private information or create additional risk.
